# 天家宗仪拓展

版本 0.1.0。2026-10-11 已按本地天家宗仪 V0.76（Workshop manifest `5109611154849456445`）同步必要更新，当前游戏安装为 CK3 1.20.0.4。宗室八等爵位与继承体系来自 MyKings 的 9ee4ac6 稳定版本，并保留原有爵位收益、贤能调整、册立保地与相关修复。皇太孙新册封现已暂停；已有皇太孙保留身份和必要退出清理。

## 启用

在启动器同一个播放集中按以下顺序排列：

1. 天家宗仪 V0.76（Steam Workshop 3684849062）。
2. 天家宗仪拓展（本子 Mod）。

关闭旧的 MyKings，避免加载两套实现。本次安装不会自动调整播放集。子 Mod 依赖原 Mod 的素材和其他功能，不能单独启用。

如果启动器提示缺少依赖，先检查天家宗仪的显示名与版本；作者改名或更新后，需要对照覆盖清单重新适配，不能仅改依赖名称便视为兼容。

## 保留内容

- 已有皇太孙的独立特质、待遇、继承评分、肖像、中文称谓、废黜与换储/登基清理。新册封入口隐藏，玩家交互、太子死亡事件、延迟册封事件和授予效果均关闭；没有游戏内开启按钮。
- 亲王、郡王与六级下爵；世子/长子身份、成年派生、长房递归、待成年承袭、指定袭爵、高爵保护。
- 手动补授、只夺本人、世系夺爵、旧王号清理、父系变化重算及实封藩王隔离。
- 太子/王爵/公侯伯子收益，太子 5000 与太孙 4000 继承加分，手动封王 2000 与玩家立太子 3000 贤能奖励。
- 册立太子保留已有实地；既有太孙不因暂停新册封而失去实地；纯宗室夺爵不改变领地、封臣或政府。

原版 V0.76 的东宫、分家宗亲、继承法、指定继承人评分、左右按钮和其他新增内容继续保留。全局姓名格式跟随 V0.76，宗室称谓继续通过专用前缀显示。

本轮同步上游的“大礼议”“册封宗亲”等典章决议及选人界面的姓名显示，保留皇太孙从大封诸皇子候选中排除的规则。GUI 本地化仅有空白差异，未改动该文件。

## 来源与回滚

`submod-manifest.json` 列出发行文件、哈希、对应上游版本及覆盖原因。子 Mod 只包含独立新增内容和必要覆盖文件，未复制原版贴图或其他未改内容；没有设置广泛 replace_path。

原 MyKings 与 Workshop 保持原样。回滚时停用“天家宗仪拓展”，恢复原播放集和测试前存档副本；不要仅靠停用子 Mod 恢复已经保存的游戏状态。

仅撤回上游同步与太孙维护可从本仓库的修改前基线 `75f76f2` 逐文件恢复对应路径，并恢复测试前存档。2026-10-11 复查时，该维护已提交为 `fd95957`。

普通册封新增 54 个一字王号：古国与地望 30 个、德行雅称 24 个，完整名单见[已确认计划](.codex/plans/2026-10-11-single-character-wanghao-expansion.md)。从普通“册封王爵”进入两类即可选择；原窗口继续滚动显示全部选项，返回项仍在开头。
